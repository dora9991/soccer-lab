# サッカー分析ラボ

**▶ [ブラウザで試す（公開ページ）](https://dora9991.github.io/soccer-lab/)** — 開くと自動デモが始まります。動画はブラウザの中だけで処理され、どこにも送信されません。

> Browser-only soccer match tagging & analysis tool (Japanese UI). Tag events on your match video → player stats, xG, shot map, goals-for/against clips with export, and coaching advice. No server, no upload — everything runs in your browser.

試合動画に「タグ」を付けるだけで、**個人成績（ゴール・アシスト・シュート・ファウル…）・xG（ゴール期待値）・ショットマップ・得点/失点シーンのハイライト動画・アドバイス**を自動で作るブラウザアプリです。
プロの現場（Hudl Sportscode / Wyscout / Opta / StatsBomb など）と同じ「イベントをタグ付けして、位置とxGで分析する」方式です。同じ作りのバスケ版（バスケ分析ラボ）もあり、キー配置もできるだけ揃えています。

## 起動

- **インストール不要**：上の公開ページを開くだけで使えます。自分のパソコンで使う場合は、下のどちらかで開きます。
- **`dist/soccer-analyzer.html`**（1ファイルにすべて入った版）をダブルクリック。他の人に渡すときはこのファイル1つでOKです。
- 開発用：`index.html` をダブルクリック（同じ内容。`js/` `css/` を読み込みます）。
- どちらも Chrome / Edge 推奨。開くと**自動デモ**（約1分半）が始まります。クリック・キー入力・スクロールをした瞬間にデモが止まり、サンプル試合（20分ハーフの架空の試合）を自由に操作できます。
- サーバーで開く場合：`node tests/devserver.cjs`（キャッシュしない開発用。このフォルダだけを配信します）→ http://127.0.0.1:8766/

## 使い方（自分の動画）

1. 右上「📂 動画を読み込む」（ドラッグ＆ドロップも可。動画は外部に送信されません）
2. `Space` で再生。**背番号 → プレーのキー**でタグ付け（例：`1` `0` → `Q` ＝ #10 のゴール）
   - ゴールの直後：ラストパスの背番号を入力（`Enter` で確定）→ **アシスト**になります（シュートが外れたときは **キーパス**）
   - ファウルの直後：ファウルを受けた相手の背番号 → 「受けたファウル」が集計されます
   - ボールロストの直後：`1`〜`6` で種類（パスミス／ドリブルで奪われた／トラップミス…）
3. 「ピッチ上の位置」の図をクリックしてからタグを付けると、シュートは**xG・ゾーン別**に、ボールロスト・ファウルは**場所別**に集計されます（任意）。`H` で次のシュートを「ヘディング」に。
4. 「集計」「場面別」「ショット」「アドバイス」「ハイライト」タブに結果が自動で出ます。

### キー一覧

| キー | 内容 | キー | 内容 |
|---|---|---|---|
| `Q` | ゴール | `Z` | ボールロスト |
| `W` `E` `R` | 枠内（止められた）／枠外／ブロックされた | `X` | ファウル（犯した） |
| `T` `Y` | PK 成功／失敗 | `B` | オフサイド |
| `U` | オウンゴール | `J` `K` | イエロー／レッド |
| `A` `S` | アシスト／キーパス | `N` | メモ（しおり） |
| `D` `F` `G` | タックル／インターセプト／クリア | `H` | 次のシュートをヘディングに |
| `C` | コーナーキック | `V` | 自チーム↔相手チーム |
| `,` `.` | 攻撃の型（カウンター・クロス…）を切替 | `L` | 攻撃の型を固定 |
| `←→` `↑↓` `[ ]` | 5秒移動／前後のタグ／再生速度 | `Backspace` `?` | 取り消し／ヘルプ |

## できること

| 機能 | 内容 |
|---|---|
| 個人集計 | ゴール・アシスト・シュート・枠内・**xG・xA**・キーパス・タックル・インターセプト・クリア・ボールロスト・**ファウル（犯した／受けた）**・カード・オフサイド・GKのセーブ |
| チーム比較 | 左右の棒で比較（優勢な側が緑）。**xGの推移グラフ**（クリックでその時点の映像へ）、前半／後半別、アシストのつながり |
| **得点と失点の内訳** | ゴールを**攻撃の始まりから**分類。失点は「PK／CK／FK／スローイン／ボールロスト直後／カウンター／クロス／縦パス・ロング／ミドル／個人技／組み立て」、得点は同じ分類で「自分たちの決め方」 |
| 場面別 | 攻撃の型別（シュート・枠内・ゴール・xG/本）、**ボールロスト**（種類・場所・選手・ロスト直後のピンチ）、**ファウル・カード**（選手・場所・前後半・FK/PKにつながった数）、セットプレー、時間帯別 |
| ショットマップ | ピッチ上に撃った位置と結果（円の大きさ＝xG）。ゾーン別に色分け（本数／xG／得点）。相手を選ぶと「どこから打たせているか」 |
| アドバイス | xGと結果のずれ・失点の原因・ボールロスト・ファウル・セットプレー・時間帯から、原因の仮説 → 練習メニュー → 該当シーン（▶）を自動で提案。選手ごとのコメントつき |
| **ハイライト** | **得点を決めた場面／決められた場面**を、攻撃の始まりからゴールまでまるごと切り出し。原因（型）で絞り込み → 開始・終了を映像を見ながら調整（◂▸／⇤⇥）→ 📝コメント → テロップ・スコア表示つきの動画に書き出し。ほかにベストプレー、決定機、GKのセーブ、ロスト→ピンチ、ファウル、押し込まれた時間帯など |
| 保存 | このブラウザに自動保存。JSON／CSV 書き出し可 |

## 指標の考え方（プロの見方を簡略化）

- **xG（ゴール期待値）**：撃った位置（ゴールまでの距離と、ゴールが見える角度）・ヘディング・攻撃の型から、そのシュートが決まる確率を概算した簡易モデルです。合計すると「取れるはずだった得点」の目安になり、結果とのずれで「決定力の問題か、運か」を切り分けます。**守備者やGKの位置までは見ないので、Opta／StatsBomb の値とは一致しません**（位置未入力のシュートは平均値で概算）。PKは 0.76。決定機は xG 0.3 以上。
- **xA**：アシスト／キーパスの相手が撃ったシュートの xG の合計。
- **失点の分類**：ゴールの直前25秒までさかのぼり、自チームのミス／相手の奪取／ファウル／コーナー／相手のシュート、を「攻撃の始まり」の目印にします。
- **目安の数値**（枠内率・決定率・ファウル数など）は一般的な傾向をもとにした参考値です（プロ／大学・高校／中学・少年）。サンプルが少ないときは断定せず、必ず映像で確認してください。

## 正直な注意点

- 映像から選手やシュートを**自動認識する機能はありません**（精度を保証できないため）。タグ付け方式です。
- ボール支配率・パス成功率のように、全プレーを記録しないと出せない指標は自動では出しません（支配率は分かる場合だけ設定で手入力できます）。
- 動画の書き出しはブラウザの録画機能を使います（Chrome / Edge 推奨、書き出し中はタブを表示したまま。動画の長さと同じ時間がかかります）。

## 開発メモ

- `js/` の各ファイルは通常の `<script>`（ビルド不要）。ファイル1つ版は `node build.mjs` で `dist/` に作り直せます。
- 回帰テスト：`node tests/run.cjs`（集計・xG・得点/失点の分類・アドバイス・サンプル生成の整合性 22件）。`tests/probe-*.cjs` は数値を眺める用、`tests/pick-seed.cjs` はサンプル試合のシード選び、`tests/viewer.html` はサンプル映像だけを確認する画面です。
- サンプル試合は `js/sim.js`（シード 335 固定のシミュレーション）が映像とタグを同時に生成します（22人の動き・ボール・シュート結果・ファウル・カード・オフサイド・セットプレー）。描画は `js/simdraw.js`。
- 確認済み：自動デモ通し／キー・マウスでのタグ付け（ラストパス・被ファウル・ロストの種類のフォローアップ含む）／全タブ／ハイライトのプレビュー・トリム・コメント・書き出し（サンプル映像）／書き出した動画を実動画として読み込み／保存できない環境での起動。
- 未確認：ブラウザのファイル選択ダイアログ経由の動画選択（ドラッグ＆ドロップと同じ処理を通ります）、Safari / Firefox、音声つき実動画での書き出し。
